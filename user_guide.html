1. What DAR Compass does

DAR Compass takes two LC-MS deconvolution exports — one for your naked (unconjugated) mAb reference and one for the ADC — and automatically works out the Drug-to-Antibody Ratio (DAR) distribution, the same way it would be done by hand in a spreadsheet, but without the manual peak-by-peak matching.

It runs three steps automatically:

1. Build a theoretical mass ladder. Using your mAb's observed mass and the linker-payload MW(s) you specify, it calculates every possible combination of "mAb + n payloads" you tell it to consider.

2. Match observed peaks. Every peak in your ADC file is compared against that ladder and assigned to its closest theoretical species — but only if it's within the mass-accuracy tolerance you set. Peaks that don't fit anywhere (fragments, adducts, noise) are automatically excluded.

3. Calculate DAR. Each matched species is weighted by its relative intensity, multiplied by its payload count, and summed — giving you a DAR value per payload type and a Total DAR.

Peaks that could plausibly match more than one species within tolerance are flagged as ambiguous rather than silently resolved, so you can review them before trusting the number.

2. Before you start

What files you need

Two Excel (.xlsx) files, each a deconvoluted intact-mass export (e.g. from Thermo BioPharma Finder or similar deconvolution software):

FileWhat it isRequired columns
mAb reference exportNaked, unconjugated antibody — same molecule, no payloadAverage Mass, Sum Intensity
ADC exportThe conjugated sample you want the DAR forAverage Mass, Sum Intensity
Why the mAb file matters: its most abundant observed mass becomes the "base mass" that all theoretical ADC species are built from. This captures natural glycoform/adduct variation in the antibody itself, separate from payload conjugation.

What you need to know before opening the app

  • The MW of every linker-payload chemistry used on this molecule (in Da).
  • The maximum number of conjugation sites for each chemistry (e.g. up to 8 for interchain-cysteine conjugation).
  • Whether conjugation happens one at a time or only in pairs (e.g. per disulfide bond) — this sets the count step (1 or 2).
  • Whether you've observed unexpected linker-payload breakage under harsh sample processing — if so, the additional mass(es) that breakage produces, and whether each still represents a "loaded" site for DAR purposes (see Step 3 below).

3. Step-by-step walkthrough

  1. Upload your two files

    In the sidebar, upload the mAb reference export and the ADC export. Both must be .xlsx files with at least Average Mass and Sum Intensity columns — the app checks this automatically and will tell you if a required column is missing.

  2. Set the number of linker-payload chemistries

    Most ADCs use one payload chemistry; some use two (e.g. a dual-payload or mixed-conjugation design). Set the count, then an expandable panel appears for each one.

  3. Configure each chemistry

    For each payload chemistry: tick Include in analysis, give it a short label (e.g. 4, 12, or a payload name), and set its maximum conjugation count and whether counts step by 1 or 2.

    Each chemistry needs at least one mass variant — its MW in Da. If it's a normal intact linker-payload, one variant is all you need. If you've seen breakage under harsh processing, increase "Number of mass variants" and enter the additional mass(es); DAR Compass treats breakage as independent per attachment site, so a single molecule can have some sites intact and others broken simultaneously. Each variant also has a DAR weight (1.0 by default): leave it at 1.0 if a broken site should still count as a full payload, or lower it (down to 0.0) if that broken form means the payload is partially or fully lost. This is a chemistry-specific judgment call — DAR Compass won't guess it for you.

  4. Set the ADC fractional abundance threshold (optional)

    Before any mass matching happens, you can raise this threshold (%) to drop very low-abundance ADC peaks — noise, minor adducts, trace contaminants — from consideration entirely. Only peaks at or above the threshold become "candidate" species. Leave it at 0 (the default) to consider every peak in the file, which is the safest starting point; raise it only if you're seeing a lot of low-abundance clutter in your results.

  5. Set the mass accuracy tolerance

    The ppm tolerance controls how far an observed mass can be from a theoretical mass and still count as a match. 250–350 ppm reproduced manually-curated results for ~150–165 kDa intact ADC species during validation — start there and adjust based on your own instrument/method performance.

    Using more than one mass variant needs a tighter tolerance. A second mass variant doesn't just add one more theoretical mass — it adds every possible split of that chemistry's site count between the variants, so the theoretical ladder gets much denser. In testing, one breakage variant with a 350 ppm tolerance flagged most matches as ambiguous. Start narrower once you're using multiple variants, and use the grid-size warning and the "Mass variants configured" panel (see below) to sanity-check your setup.

  6. Choose how many mAb base masses to use

    Most abundant only (recommended) anchors everything to the single dominant mAb mass. Top N variants includes minor glycoform/adduct masses too — useful for exploratory runs, but can introduce ambiguous matches if those variants are close in mass to each other.

  7. Click "Run DAR analysis"

    Results appear in the main panel: DAR metrics, a drug-load distribution table and chart, a species-level distribution chart, a matched-species table, and download buttons. Once shown, results stay on screen while you interact with the chart-detail toggle or any other widget — only clicking "Run DAR analysis" again recomputes them.

  8. Review the drug-load distribution table and chart

    One row (and one chart panel) per chemistry, showing the % of matched intensity at each individual count — independent of the other chemistries — plus an Average column matching the DAR metric above. This is the standard report format: blank cells for counts outside that chemistry's configured range, and the modal (most abundant) count highlighted, same as you'd see in a characterization slide.

  9. Toggle chart detail on the species-level chart (only shown if a chemistry has multiple mass variants)

    Detailed shows every intact/broken mixture as its own bar — precise, but can get crowded once a chemistry has multiple mass variants. Consolidated groups bars by total occupied-site count per chemistry only, hiding which specific variant(s) made up that total. This only changes this chart; the table below and the DAR numbers above are identical either way.

  10. Review anything flagged ambiguous

    If any matched peak could plausibly belong to more than one species within your tolerance, it's highlighted in the table and counted in a warning banner. Check these before reporting the DAR value.

  11. Check the Selection summary table

    A quick funnel: total ADC peaks → excluded by the abundance threshold → candidates → matched → unmatched, shown as both a peak count and a % of total signal (Fractional Abundance). These two percentages are meant to diverge sometimes — matching a small fraction of peaks by count can still mean capturing nearly all of the real signal, since low-abundance noise peaks are expected to go unmatched. A low peak-count % alongside a high signal % is normal and fine; a low signal % is the one worth investigating in the verification table below.

  12. Open "Peak-by-peak verification" if anything looks off

    Lists every peak in the ADC file, matched or not, with its closest theoretical species and ppm error. Rows are color-coded: green = matched, yellow = excluded by the fractional abundance threshold before matching started, red = passed that threshold but still too far in ppm from anything in the theoretical grid. A red row on a peak you expected to match almost always means a chemistry's max conjugation count (or a mass variant's MW) needs adjusting — the theoretical grid simply doesn't reach that peak yet, rather than the peak being noise. This is exactly the signal that caught a real misconfigured max-conjugation-count issue in practice (see ACE723_discrepancy_diagnosis.md for the full worked example).

  13. Download your report

    Use the download buttons to save the DAR report as an Excel file — summary, Selection Summary, drug-load distribution, full matched-species table, and an Analysis sheet with every parameter used, the full theoretical mass grid, and the peak-by-peak verification table, each on its own sheet — plus both charts as PNGs, for your records, an ELN/LIMS entry, or so someone else can check the result by hand without re-running anything.

4. Understanding your results

DAR metrics

One metric per payload chemistry (e.g. DAR [4], DAR [12]) plus Total DAR, the sum across all chemistries — matching the standard intensity-weighted calculation: relative abundance × payload count, summed across matched species.

Distribution chart

Bars show relative abundance per matched species, sorted highest to lowest. Blue bars are unambiguous matches; orange bars are ambiguous and worth a closer look. Use the Chart detail toggle (visible when a chemistry has multiple mass variants) to switch between the full mixture breakdown and a consolidated view grouped by total count per chemistry.

Matched species table

Every accepted peak, its assigned species, mass accuracy (ppm), relative abundance, and payload counts. For a chemistry with more than one mass variant, you'll see a count column per variant (e.g. one for the intact form, one for each breakage variant) plus a combined total column. Rows shaded light orange are ambiguous — the runner_up_species and runner_up_ppm_error columns show the next-closest alternative so you can judge which is more plausible.

The "Mass variants configured for this run" panel above the chart lists every chemistry's variants with their MW and DAR weight, so you can double-check your setup before trusting the results.

An ambiguous flag doesn't mean the match is wrong — it means two labels were both mathematically plausible within your tolerance. Narrower tolerance, or excluding minor mAb mass variants from the base-mass set, usually resolves most of these. If you're using multiple mass variants on a chemistry, expect more ambiguous flags than usual (see the tolerance note in Step 5 of the walkthrough) — it's a sign to tighten tolerance or simplify the configuration, not necessarily a data problem.

5. Tips for reliable results

  • Start with "Most abundant only" for the base mass setting. Add more variants only if you specifically need to account for minor glycoforms and you're seeing unmatched major peaks.
  • Don't chase <20 ppm. For intact species in the 150–165 kDa range, 100–300 ppm is normal instrument/deconvolution performance — a tolerance that's too tight will simply drop real species rather than improve accuracy.
  • If nothing matches, widen the tolerance gradually rather than jumping straight to a very large number — that makes it easier to spot when unrelated species start getting pulled in.
  • Keep the fractional abundance threshold at 0 by default. It's a coarse pre-filter, not a replacement for the ppm tolerance. Raise it only when you can see specific low-abundance peaks cluttering your results and want them excluded before matching even happens — otherwise you risk dropping a real, low-intensity minor species along with the noise.
  • Cross-check Total DAR against expectation. If your conjugation chemistry caps out at, say, 8 sites, a Total DAR far outside a plausible range is a sign to review the ambiguous matches or reconsider the payload/MW inputs.

6. Troubleshooting

"Please upload both a mAb reference file and an ADC file"
Both file slots in the sidebar need a file before you click Run — check neither was left empty.
"...is missing expected column(s)"
Your export doesn't have an Average Mass or Sum Intensity column with that exact name. Check your deconvolution software's export settings, or rename the columns to match.
"No ADC peaks remain at this fractional abundance threshold"
Your fractional abundance threshold filtered out every peak in the file before matching even started. Lower it — most files won't need it set above a fraction of a percent.
"No peaks matched at this tolerance"
Increase the ppm tolerance slider. If that doesn't help, double-check your payload MW values and maximum conjugation counts — a wrong MW will mean no theoretical mass ever lines up with your data. Also confirm the fractional abundance threshold isn't set higher than intended.
Total DAR looks too high or too low
Check for ambiguous matches first. If none, confirm the count step (1 vs 2) matches your conjugation chemistry, and that "Max conjugation count" is set high enough to cover your ADC's expected range.

7. Running the app

On your own computer

pip install -r requirements.txt
streamlit run app.py

This opens DAR Compass in your browser at http://localhost:8501.

Shared on the team network

pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501

Anyone on the same network can then reach it at http://<server-hostname>:8501. For anything beyond same-network access, loop in IT for a proper reverse proxy / login setup.

Shared publicly online (e.g. Render)

DAR Compass can also be deployed on a hosting service like Render to get a public URL for sharing with an outside colleague — see the "Deploying on Render" section of README.md for step-by-step instructions, including the render.yaml config included in this delivery. Because a public URL has no built-in login, the app includes an optional password gate (set via an APP_PASSWORD environment variable) that's strongly recommended once it's off your local network.
